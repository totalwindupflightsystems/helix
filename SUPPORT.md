# Support

Helix is an agent-first code platform currently in active development.

## Getting Help

- **Documentation:** See `AGENTS.md` for project structure and development guide
- **Specifications:** See `specs/` directory for detailed feature documentation
- **Issues:** File issues on the project's Forgejo/GitHub repository

## Community

Helix is primarily developed as part of the TotalWindUpFlightSystems ecosystem. For questions about architecture, integration, or contribution, refer to the project specifications and existing documentation.

## Supported Versions

Helix follows a rolling release model. The latest commit on the main branch is the supported version.

## Reporting Security Issues

See `SECURITY.md` for the security vulnerability disclosure policy.
