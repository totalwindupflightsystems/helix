# GAP-004 — Prompt layout unification: path-style attestations

## Context

Helix commit messages carry path-style prompt trailers per AGENTS.md:

```
Prompt: prompts/<name>/v<N>.md
```

But `pkg/prompt`'s attestation pipeline only understands hash-style
trailers (`Prompt: sha256:<hex>`, spec §8.1). As a result:

- `helix prompt verify HEAD` fails on every repo commit with
  `ATTESTATION_MISSING: no 'Prompt: sha256:<hash>' line found`.
- `prompt register` writes the nested registry layout
  (`prompts/<component>/<version>/prompt.md`, spec §3.1) while the repo's
  committed prompt files use the flat layout (`prompts/<name>/v<N>.md`).
  Both layouts are already supported by `ResolvePromptPath`.

## Task

Make the attestation pipeline accept BOTH attestation formats:

1. `Prompt: sha256:<hex>` (existing, spec §8.1)
2. `Prompt: prompts/<name>/v<N>.md` (flat, AGENTS.md convention)
3. `Prompt: prompts/<component>/<version>/prompt.md` (nested, registry layout)

so `helix prompt verify HEAD` works on the repo's own commits.
