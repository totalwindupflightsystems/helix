# SRC-002 — Multi-source integration Muster bridge

## Goal

Create a Muster bridge package (`pkg/source/muster_bridge.go`) that generates MCP
(Model Context Protocol) tools from OpenAPI specs using Muster. This is a Go library
in the Helix project.

## Requirements

1. **pkg/source/muster_bridge.go** with types and functions to:
   - Connect to a Muster instance (configurable base URL)
   - Read OpenAPI specs (local files or URLs)
   - Call Muster's API to generate MCP tool definitions from those specs
   - Return a structured `ToolSet` that Helix can use for multi-source integration

2. **pkg/source/muster_bridge_test.go** with comprehensive tests:
   - Basic initialization and configuration
   - OpenAPI spec loading (with test fixtures)
   - Tool generation with mock Muster responses
   - Error handling for unavailable Muster instances
   - Edge cases (empty specs, malformed specs, etc.)

3. Follow existing patterns:
   - `pkg/source/config.go` for Source/YAML parsing patterns
   - `pkg/integration/` for adapter patterns (muster_client.go already exists)
   - Use standard Go error handling (`fmt.Errorf`)

4. Build, vet, test, and gofmt all pass.

## Key Types

- `BridgeConfig` — connection config (BaseURL, Token, Timeout)
- `MusterBridge` — wraps `integration.MusterClient` with spec-loading
- `ToolSet` — collection of generated MCP tools with metadata

## Dependencies

- `pkg/integration` (imported adapter — MusterClient, MCPTool, GenerateOpts, etc.)
- `pkg/source/config.go` (Source struct for GenerateToolsFromSource)
