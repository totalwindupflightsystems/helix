# GAP-008 — known-friends default path fallback + NO_AGENTS on empty file

## Context
`helix identity provision` hardcodes the default `--known-friends` path to
`/opt/hermes-demo/.hermes/h4f/known-friends.json` — a dead path from a
different deployment. On hosts without that file, the README/GETTING-STARTED
command fails with a confusing cross-project FILE_NOT_FOUND.

## Changes
- `cmd/helix-identity/main.go`: new `defaultKnownFriendsPath()` — os.Stat
  prod path if present, else `~/.helix/known-friends.json` (user-local).
- `pkg/identity/syncer.go` `LoadKnownFriends`: empty/whitespace file loads
  as an empty agent map (no agents, not malformed); FILE_NOT_FOUND carries
  a `--known-friends` / `HELIX_KNOWN_FRIENDS` hint.
- `cmd/helix-identity/main.go` `runProvision`: empty known-friends prints
  `NO_AGENTS` and exits 0 (mirrors runSync).

## Acceptance
`HELIX_KNOWN_FRIENDS=$(mktemp) helix identity provision test-agent` exits 0
with `NO_AGENTS: known-friends.json contains no agents` instead of a
hermes-demo path error.
