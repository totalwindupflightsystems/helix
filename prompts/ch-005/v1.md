# CH-005 — Channel CLI: helix channel create/join/send/list/archive/history

## Context

SPEC-024 (specs/agent-communication-channels.md) §8: the CLI surface for
agent communication channels. pkg/channel is complete (CH-001..004): channel
+ message types with SSE streaming (channel.go), HID signing/verification
(message.go), Chimera auto-trigger (deliberation.go), DuckBrain archival
(archive.go). CH-005 adds the operator-facing CLI: `cmd/helix/channel.go`,
mirroring the proven `cmd/helix/source.go` pattern (SPEC-025 §7).

## Requirements

- `helix channel create  --name STRING --type [task|review|deliberation|incident] --members AGENT,AGENT`
  — create a channel; validate type; upsert semantics for members.
- `helix channel join    --name STRING` — join a channel (add current agent
  as member; idempotent when already a member).
- `helix channel send    --channel STRING --message STRING [--attachment PATH]`
  — append a signed message (HIDProof via channel.SignMessage).
- `helix channel list    [--status active|archived]` — table of channels.
- `helix channel archive --name STRING` — verify every message's HIDProof via
  channel.ArchiveChannel (fail closed) and mark the channel archived;
  report Written/Skipped.
- `helix channel history --name STRING [--limit N]` — messages, timestamp
  ascending, limited by N.

Pattern rules (from source.go): exit code 0 on success, 2 on validation
failure/error, `--help`/`-h` prints usage; persistence in
`.helix/channels.yaml` with `HELIX_CHANNELS_FILE` env override;
gopkg.in/yaml.v3 (already in go.mod). Wire `case "channel"` into
cmd/helix/main.go dispatch switch and printUsage.

Messages must be signed (channel.SignMessage) and archive must verify
(channel.VerifyMessage / channel.ArchiveChannel) — the CLI persists a local
agent identity (pkg/identity.NewAgentIdentity) for this.

Tests: cmd/helix/channel_test.go covering flag parsing, validation
failures (exit 2), create/list roundtrip, join idempotency, send signs,
history ordering + limit, archive verification + idempotent re-archive,
unknown subcommand.

Constraints: no new external dependencies; do not modify files outside
cmd/helix/channel.go, cmd/helix/channel_test.go, cmd/helix/main.go;
do not run go mod tidy; gofmt clean.
