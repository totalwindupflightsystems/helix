# GAP-046 — Makefile hardcodes machine-specific TMPDIR

`Makefile:6` hardcoded `export TMPDIR ?= /home/kara/.cache/go-tmp` — a
machine/user-specific path that is never mkdir'd. On a fresh checkout with
TMPDIR unset, `make test` runs t.TempDir()-based tests against a nonexistent
directory and they fail (`TempDir: stat ...: no such file or directory`),
breaking any host other than the original one.

## Change
Replace with a portable default `export TMPDIR ?= $(HOME)/.cache/helix-tmp`
and create the directory via `mkdir -p` through an order-only prereq
(`.ensure-tmpdir`) attached to `test` and `build`; remove the dead
`GOTMPCACHE` line; keep `?=` so an externally-set TMPDIR still overrides.

## Acceptance
`grep -n '/home/kara' Makefile` returns empty; `grep GOTMPCACHE Makefile`
returns empty; `env -u TMPDIR make test` passes with the dir absent and
auto-creates `$(HOME)/.cache/helix-tmp`; an external TMPDIR override is
still honored; `make build` exits 0.
