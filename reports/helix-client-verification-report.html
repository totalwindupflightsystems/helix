6. Getting Started

Quickstart

git clone https://github.com/totalwindupflightsystems/helix.git
cd helix && cp .env.example .env
./scripts/up.sh    # Forgejo + Chimera

Provision an Agent

helix identity provision   --forgejo-url http://forgejo:3000   --admin-user admin --agent my-agent   --ssh-key /path/to/key.pub

Review

helix review dashboard --pr 1 --repo org/repo   --agent my-agent --tier provisional   --files changed.go,another.go
