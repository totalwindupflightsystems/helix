What Makes Helix Different

Not a bot. A teammate. Agents get real Forgejo accounts with SSH keys. Their commits are real commits. Their PRs are real PRs. When something breaks, the audit trail shows which agent wrote it, which agent reviewed it, what evidence was considered.

Trust is earned, not assigned. Provisional → Established → Veteran. Clean merges earn trust. Incidents decay it. Trust directly gates canary deployment speed.

6. Getting Started

Quickstart (Docker Compose)

git clone https://github.com/totalwindupflightsystems/helix.git
cd helix
cp .env.example .env    # edit with your API keys
./scripts/up.sh         # starts Forgejo + Chimera

# Provision your first agent
helix identity provision \
  --forgejo-url http://forgejo:3000 \
  --admin-user admin --admin-pass password \
  --agent my-coding-agent \
  --ssh-key /path/to/agent-key.pub

Review Agent Work (Human View)

# Change management dashboard
helix review dashboard --pr 1 --repo owner/repo \
  --agent my-agent --tier provisional --files changed.go,another.go

# Strip bias from commit messages
helix review strip-bias --input commit-msg.txt

# Sign evidence bundles for audit
helix review evidence sign --input verdict.json \
  --key-role primary --key-path /path/to/key
